# ChordFlow Piano

First Flutter prototype for a piano chord and progression app.

## Current features
- Chord library
- Chord selection
- Beautiful progression generator
- Favorites saved locally
- Piano keyboard visualization

## Run
1. Install Flutter.
2. Run `flutter pub get`
3. Connect an Android phone or start an Android emulator.
4. Run `flutter run`

Next development step: add real piano audio, full keyboard/octaves, inversions, transpose, progression playback, and category-based progression libraries.
